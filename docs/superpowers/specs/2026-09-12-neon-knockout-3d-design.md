# Neon Knockout 3D approved direction

Build a separate GitHub repository, neon-knockout-3d, from the existing published Neon Knockout main. The user's approval covers a complete 2.5D conversion with all four characters visually and mechanically distinct and publication to the new repository. Preserve the source working checkout and unrelated services.

Use Three.js for all match rendering, replacing Phaser rather than shipping a second renderer. Preserve the authoritative Node simulation, Socket.IO lobby, WebRTC gameplay path, adaptive presentation and local prediction. Keep game rules two-dimensional; project simulation coordinates (x,y) into world (x,height,z=y). Authored procedural articulated robots and original local audio need no downloaded model licenses or online runtime assets.

Abilities use the existing dash input: Space on keyboard and the existing touch dash control. RIFT performs a longer fast rush; BASTION performs a slower armored advance with reduced knockback; PULSE releases a radial repulsion at dash start with a longer cooldown; WRAITH phases with a longer invulnerability window. Different base movement speeds and cooldowns must be shared by the authoritative simulation and local prediction. Invulnerability, hit credit, ability spam prevention, respawn, and disconnect rules must remain server controlled. Export display metadata from src/shared/fighters.ts so the lobby and HUD describe actual rules.

First deliverable includes lobby character previews, fixed-camera 3D arena, four different articulated models, idle/travel/attack/heavy/dash/hit/knockout/respawn motions, readable pulses and attack cues, sound, cooldown feedback, real two-client combat and reconnect smoke checks. Default LAN port is 4175 to avoid the original game's 4174 service. Run static checks, simulation/unit/integration suites, appropriate browser journeys and a rendered eight-player performance scenario. Report physical second-device testing separately from same-host multi-client tests.
